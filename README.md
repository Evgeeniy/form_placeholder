# 🚀 Инструкция по установке и запуску

Данный скрипт автоматизирует работу в браузере. Для управления зависимостями используется инструмент `uv`, который автоматически установит нужную версию Python и все библиотеки из вашего `pyproject.toml`.

## 1. Подготовка данных

Перед запуском откройте файл `data.json` в текстовом редакторе и укажите необходимые номера заявок и лотов:

- Отредактируйте поле `application_numbers` и `lot_numbers` (согласно формату в файле).

- Сохраните файл.

---

## 2. Установка менеджера `uv`

Выберите команду в зависимости от вашей операционной системы:

### **Windows**

Откройте **PowerShell** и выполните:

PowerShell

```
powershell -c "ir https://astral.sh/uv/install.ps1 | iex"
```

### **Linux & macOS**

Откройте **Терминал** и выполните:

Bash

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

*После установки на Linux/Mac может потребоваться перезапустить терминал.*

---

## 3. Установка проекта и запуск

С помощью `uv` вам не нужно вручную устанавливать Python. Скрипт сам создаст виртуальное окружение и скачает всё необходимое.

### **Шаг 1: Переход в папку**

Откройте терминал (или командную строку) и перейдите в папку с распакованным архивом:

Bash

```
cd путь/к/вашей/папке
```

### **Шаг 2: Синхронизация проекта**

Эта команда прочитает ваш `pyproject.toml`, установит правильную версию Python и все зависимости:

Bash

```
uv sync
```

### **Шаг 3: Запуск скрипта**

Запустите основной файл:

Bash

```
uv run main.py
```

---

## 4. Использование

1. После запуска в терминале появятся инструкции.

2. Следуйте подсказкам: скрипт может попросить вас пройти авторизацию или подтвердить начало действий.

3. **Внимание:** Не закрывайте окно браузера, которое откроет скрипт, до завершения работы.

---

## 🛠 Устранение неполадок

- **Ошибка Chrome/WebDriver:** Убедитесь, что у вас установлен браузер Google Chrome последней версии.

- **Файл data.json не найден:** Убедитесь, что вы запускаете команду `uv run main.py` именно из той папки, где лежит этот файл.

- **Права доступа (Linux):** Если скрипт не запускается, попробуйте дать права на выполнение: `chmod +x main.py`.
